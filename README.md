# 🌐👋 RestApi Hello World App 
## 📘 About The Project
This is a basic Flask application that demonstrates how to create a simple REST API in Python. The application responds to a `GET` request on the root endpoint (`/`) with a "Hello, World!" message.

## 🚀 Getting Started
## 🔧 Prerequisites
Make sure you have Python installed on your system. You can check your version by running:
```bash
python --version
 ```
Must be at least **3.8.3**

## 📥 Installation
1.- Clone the repository

   ```sh
   git clone https://github.com/Jesdhy/restApi-Hello-World.git
  ```
2.- Set up a virtual environment:
   ```sh
python -m venv venv
source venv/bin/activate  # For Linux/MacOS
venv\Scripts\activate     # For Windows
  ```
3.- Install the dependencies:
   ```sh
pip install flask
  ```
## ⚙️ Running
1. Start the Flask server:
```sh
python app.py
```
2. Open your browser and visit::
```sh
http://127.0.0.1:5000
```
